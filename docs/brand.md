# الهوية البصرية

## اللوغو

فولون (مقود) أبيض، الذراع السفلي على شكل **طريق** بخط متقطع. الكتابة **volan** بحروف لاتينية فقط.

| الملف | الاستعمال |
|---|---|
| `brand/volan-mark.svg` | الشعار على خلفية فاتحة |
| `brand/volan-mark-white.svg` | الشعار على خلفية داكنة أو خضراء |
| `brand/volan-app-icon.svg`, `-1024.png` | أيقونة التطبيق (المتاجر) |
| `brand/volan-logo-sheet.svg` | لوحة اللوغو الكاملة |

## الألوان

| الاسم | الكود | الاستعمال |
|---|---|---|
| أخضر بترولي | `#0F6B6E` | اللون الأساسي: الأزرار، الروابط، الشعار |
| أخضر بترولي غامق | `#0A4C4F` | الضغط والتمرير |
| كحل | `#0B1F21` | النصوص والخلفيات الداكنة |
| ذهبي | `#FFB020` | SOS، التنبيهات، «قريباً» |
| رمادي فاتح | `#F3F6F5` | خلفية الشاشات |
| حدود | `#DFE7E6` | الحدود والفواصل |
| نص ثانوي | `#586968` | الشروحات |
| أحمر | `#B42318` | الأخطاء، البلاغ، الحظر |

## الخطوط

- العربية: **IBM Plex Sans Arabic** (400 / 500 / 600 / 700).
- الشعار والأرقام اللاتينية: **Poppins** 600.
