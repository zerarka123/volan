# الهيكلة

## المبدأ

- **خفيف ورخيص:** لا شات داخل التطبيق، لا سيرفر خاص. كل شيء على Supabase (قاعدة بيانات + تخزين + تسجيل دخول) في الباقة المجانية في البداية.
- **التواصل عبر واتساب:** زر واتساب يستدعي الدالة `contact_listing` أو `contact_business`، التي:
  1. تسجّل سطراً واحداً في جدول `events` (للإحصائيات وللتأكد من التقييمات)،
  2. ترجع رقم البائع ورسالة جاهزة: *«السلام، شفت إعلانك على volan: …»*.
  رقم الهاتف لا يظهر أبداً في الجداول العامة، فقط عبر هذه الدالة.
- **فلتر الصور في الهاتف:** قبل رفع أي صورة، التطبيق يفحصها بـ Google ML Kit (Image Labeling، يعمل بدون إنترنت ومجاني). إذا لم يجد سيارة / عجلة / محرك / قطعة / ورشة، يرفضها ولا تُرفع. تُحفظ فقط **مصغّرة** (~10 كيلوبايت) في `photo_rejections` لتراجعها الإدارة، وتُحذف بعد 30 يوماً.
- **ضغط الصور:** حد أقصى 10 صور للإعلان، 1 ميغابايت للصورة (تُضغط في الهاتف إلى ~1280px WebP/JPEG).

## الأجزاء

```
 تطبيق Flutter ──┐
                 ├──> Supabase:  Auth (OTP واتساب)  ·  Postgres + RLS  ·  Storage  ·  pg_cron
 لوحة الإدارة ───┤
 الموقع ─────────┘   (الموقع يقرأ فقط: الإعلانات العامة)
```

## تسجيل الدخول

رقم الهاتف + كود من 6 أرقام عبر **واتساب** (Supabase Phone Auth مع مزوّد يدعم قناة واتساب)، وخيار SMS احتياطي. يجب التأكد من تكلفة المزوّد للجزائر قبل الإطلاق.

## الجداول الرئيسية

| الجدول | الدور |
|---|---|
| `profiles` | حساب المستخدم: الاسم، الهاتف (مخفي)، الولاية، نوع الحساب، الدور (`user` / `moderator` / `admin`) |
| `businesses`, `business_prices` | المحترفون (محل قطع، ورشة، دباناج، معرض) وأسعارهم المعلّقة |
| `listings`, `listing_photos` | إعلانات السيارات والقطع. تنتهي بعد 60 يوماً إن لم تُجدَّد |
| `parts_requests`, `parts_offers` | طلب قطعة → عروض المحلات. الباقة المجانية: 5 عروض/يوم |
| `bookings`, `sos_requests` | حجز الخدمات وطلبات الدباناج |
| `vehicles`, `maintenance_log` | «سيارتي»: التذكيرات ودفتر الصيانة |
| `verification_requests` | طلبات التوثيق (الوثائق في مخزن خاص) |
| `reviews` | التقييمات — مرفوضة إن لم يكن هناك تواصل حقيقي (ضغطة واتساب/اتصال أو حجز منتهٍ) |
| `reports` | البلاغات |
| `featured` | الإعلانات المميزة |
| `events` | الإحصائيات (مشاهدات، ضغطات واتساب، اتصال، بحث…) — الكتابة عبر الدوال فقط |
| `photo_rejections` | الصور المرفوضة (مصغّرات للمراجعة) |
| `feature_waitlist` | «علّمني كي تتفعّل» (مثلاً: الفحص قبل الشراء) |

## الأمان

- **RLS** مفعّل على كل الجداول.
- المستخدم لا يستطيع أن يمنح نفسه: دور مدير، شارة «موثّق»، تمييز إعلان، أو تغيير العدادات (trigger `protect_columns`).
- الحساب المحظور لا يستطيع النشر، وإعلاناته تُخفى.
- دوال الإدارة (`admin_*`) تتحقق من الدور في كل استدعاء.

## دوال الإدارة

| الدالة | الاستعمال في اللوحة |
|---|---|
| `admin_stats(from, to)` | صفحة الإحصائيات (كل البطاقات في استدعاء واحد) |
| `admin_review_verification(id, approve, reason)` | زر «وثّق» / «رفض» |
| `admin_handle_report(id, action)` | «خبّي الإعلان» / «بلوكي الحساب» / «تجاهل» |
| `admin_set_featured`, `admin_toggle_featured` | الإعلانات المميزة |

## المهام الليلية

`nightly_maintenance()` كل يوم 03:00 UTC: انتهاء الإعلانات والتمييز وطلبات القطع، حذف المصغّرات القديمة، وحذف أحداث المشاهدة/البحث بعد 180 يوماً (للحفاظ على حجم قاعدة البيانات صغيراً).
